# AppLock

A secure Android application developed by SK Software that helps users protect selected applications using PIN and supported biometric authentication.

## Features

- Protect selected Android applications
- PIN-based authentication
- Fingerprint/biometric authentication where supported
- Secure local storage of AppLock security data
- Accessibility Service used for detecting protected apps
- Usage Stats support for app foreground detection
- Clean and modern Android interface
- Google AdMob advertising

## Privacy

AppLock is designed so that its core security data remains on the user's device.
